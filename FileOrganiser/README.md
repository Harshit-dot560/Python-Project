# 📂 File Organizer (Python)

## 📌 Description

This project organizes files in a given directory into folders based on file type such as Images, Documents, and Videos.

## ⚙️ Features

* Organizes files automatically
* User selects file type
* Handles duplicate file names
* Creates folders if not present

## 🚀 How to Run

1. Run the script:

   ```
   logic.py
   ```
2. Enter the folder path
